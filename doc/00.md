# 共通部品一覧

分割後の実装に対応するソースコードを記載しています。ファイル名のリンクから実装を開けます。
「方式」は共通ライブラリの実装、「業務」は利用例・業務固有の処理・組み込み設定です。
部品名が共通処理の候補であっても、現在は業務側に実装しているものや、フレームワークの標準機能を利用しているものは、その旨を明記しています。

| 表中の区分 | Angular | Spring Boot |
| --- | --- | --- |
| 方式 | `platform-angular/` | `platform-springboot/` |
| 業務 | `business-angular/` | `business-springboot/` |

## Angularのファイル入出力部品

Spring Bootのファイル処理を利用するための、Angular側の共通処理と画面です。

| 処理 | 対象ソース（方式） | 利用箇所（業務） |
| --- | --- | --- |
| アップロード・ダウンロード通信 | [api.service.ts][source-28]（upload / download） | [files.component.ts][source-4] |
| ブラウザーへのファイル保存 | [file-download.service.ts][source-61]（save） | [files.component.ts][source-4]（download） |
| ファイル検証エラーの表示 | [api.service.ts][source-28]（FieldViolation） | [files.component.ts][source-4]、[files.component.html][source-37] |

## 組み込みの入口

- Angular方式部品の公開API：[public-api.ts][source-62]。業務側は `@example/platform-angular` からimportします。
- Angularの起動・通信設定：[main.ts][source-29]。画面ルートは [app.routes.ts][source-2]、共通UIの配置は [app.component.ts][source-1] です。
- Spring Boot方式部品の登録：[PlatformConfiguration.java][source-58]。業務側の [BusinessApplication.java][source-60] からimportします。
- 共通テーマ：[_theme.scss][source-63]。業務側の [styles.scss][source-64] から読み込みます。
